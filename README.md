# Veterans Deal Proof — Personal Preview

This repository contains a **personal-use, static prototype** of Veterans Deal Proof. It is intended for exploring and learning, not for running a production discount marketplace or commercial service.

## Try it

The entire interface is in `index.html`. It can be deployed through GitHub Pages or opened locally. The logo and UI graphics are embedded in the HTML so no additional assets are needed.

## Features

- Search a starter set of official-source U.S. veteran discount programs.
- Estimate potential veteran prices from a product price and **eligible** discount.
- Save offers and price observations in this browser's local storage.
- Record missing discounts / incorrect prices in a private personal notebook.
- Read direct retailer terms and open retailers' own websites to redeem offers.

## Important limits

- Does **not** fetch live prices or verify real-time retailer eligibility.
- "Veteran price" calculations are **estimates**, not checkout confirmations.
- Historical prices are recorded prospectively by the user; missing history is not invented.
- Reports and favorites remain on the device/browser in local storage and are **not shared** with a server or other veterans.
- Newsletter is not a live 7 a.m. email service.
- There is no purchase or payment processing within this website.
- Not affiliated with, sponsored by, or endorsed by the U.S. Department of Veterans Affairs, Department of Defense, or federal government.
- Source and discount terms may change. Review the retailer's official terms before buying.

## GitHub Pages personal preview

To use GitHub Pages on GitHub Free, the repository must be public. In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save. The published URL appears on the Pages settings screen after deployment.

GitHub Pages is for this **noncommercial personal/testing preview only**. GitHub Pages is not intended as free hosting for a commercial deal-discovery business; use hosting with appropriate terms before launching a public commercial version.
